화면 구성

- 멀티게임 기본 페이지 : 대기방 입장 버튼, 내 참여 기록(누르면 세부 결과), 게임 결과(누르면 세부 결과), 랭킹(학과별 랭킹)
- 대기방 페이지 : 안내, 참여 인원, 게임방 입장 버튼
- 게임방 페이지 : 30초 수강신청, 신청 버튼, 나가기
- 결과페이지 : 시계열 기록 (내 기록은 강조됨), 라운드 분석서, 내 신청 타임라인



### 멀티게임 기본 페이지
- 대기방 입장 버튼 누르면 대기방으로 이동
- 내 참여 기록의 각 데이터를 누르면 내 참여 기록 페이지로 이동
- 게임 결과의 각 데이터를 누르면 게임 결과 페이지로 이동
- 랭킹은 그냥 보이는 랭킹임

### 대기방
사용자는 대기방에 언제든지 들어갈 수 있습니다. 

대기방에서는 현재 참여 인원과 게임 상태를 확인할 수 있습니다
- 게임 상태가 WAITING/READY이면 "게임이 곧 시작됩니다" 보임
- 게임 상태가 CANCELLED이면 "최소 인원 미달로 취소되었습니다" 보임
- 게임 상태가 CLOSED이면 "운영 시간이 아닙니다 x 부터 x 까지는 운영되지 않습니다" 보임
- 게임 상태가 ENDED이면 "이번 회차 게임이 종료되었습니다, 다음 회차 xxx 시간 게임을 기다려주세요" 보임

게임방 입장 버튼 누를때
- 게임 상태가 PROGRESS가 아니면 "수강신청은 xxx 시간에만 가능합니다" alert
- 게임 상태가 PROGRESS이면 게임방으로 이동


### 게임방
우측 상단에 30초 타이머를 표시합니다.
우측 상단에 결과 페이지 진입 버튼 누르면
- PROGRESS 상태 이면 "게임이 진행 중입니다 게임 시간 30초 이후에 결과를 확인할 수 있습니다" alert
- ENDED 상태가 되면 30초 이후부터는 결과 확인 페이지로 진입


### 결과 페이지
- 결과 페이지에서는 시계열 기록, 라운드 분석서, 내 신청 타임라인을 확인할 수 있습니다.
- 시계열 기록은 내 기록은 강조되어 표시됩니다
